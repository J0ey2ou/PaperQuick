# AI 阅读助手：网页账号与 API

阅读文献时选中文字，右键 → **询问 AI（网页 / API）** → 解释、总结、翻译、分析方法或自定义问题。右侧“AI 阅读”页签可选择工具与接入方式，编辑选文、问题，保存自己的提问模板。

## Windows 内嵌网页

模式选择“内嵌网页”，点击“在此打开聊天”，网页出现在右侧“聊天网页”页签，无需安装扩展或复制回答。首次在独立的内嵌配置中登录；点击网页回存按钮后，进入“回答 / 笔记”保存回答。保留未发送草稿，不会用下一次选区覆盖。Google OAuth 等登录方式可能不允许内嵌；可使用外部网页 / API 模式，不保证所有站点的账号流程都可内嵌。Mac 尚未接入此 Windows WebView2 组件。

## 网页账号

可选择 ChatGPT、豆包、DeepSeek、Gemini、千问 / Qwen、Kimi。千问当前使用 `chat.qwen.ai` 网页入口。网页模式使用浏览器已有登录态，无需 API Key。首次请重新加载软件目录内的浏览器扩展 **2.6.0**，允许对应 AI 网站和本机地址访问，并刷新原有网页。

“提问 / 打开网页”会打开本机连接页，再把问题填入所选网站；默认首次附上当前阅读附件，也可以关闭此选项。正文最大 24 MB。请核对附件后自行点击网页发送，扩展不代发问题。

ChatGPT 会在确认问题发送后绑定普通对话，可点击回答下的“回存到文献直达”，也可先选中回答中的部分内容再点击。其他五家请在发送后点击扩展浮层的“发送后绑定当前对话”，然后选中所需回答，点击“回存选中的回答”。这些回存进入软件的 AI 回答区，**不会自动修改阅读笔记**；由你选择“回答 / 选中部分加入笔记”。

同一篇文献、同一个工具继续使用绑定对话，不同工具分别绑定。网页改版、登录限制、附件额度或未暴露上传控件时可能需要按提示手动展开附件菜单、手动上传或重试。不能确认附件接收时会显示失败，保留文字，不宣称已成功上传。

## API

设置 → **AI 阅读助手：网页账号 / API 设置**，或在 AI 页签点击“AI 设置”。选择工具，填写 API 地址、模型 ID、API Key；支持上述六家兼容接口及自定义 Chat Completions 服务。模型 ID 按自己的服务账号权限填写，豆包也可以使用推理接入点 ID；千问可根据账号地域修改地址。网页会员与 API 调用额度独立。

保存后可“测试连接”，只发送一句测试问题，不带文献。密钥使用当前 Windows 用户的 DPAPI 加密，留空保留已存密钥，也可删除。密钥按工具与精确 API 地址分别保存，修改地址不会把旧密钥发送到新地址。远程 API 使用 HTTPS，本机兼容服务可用回环 HTTP 地址；不跟随重定向转发认证信息。

API 回答直接在软件中逐步显示；兼容服务不支持流式输出时，在设置关闭“流式显示回答”。可停止生成，失败或不完整的回答不会写入对话历史，不自动重试付费请求。

## 上下文、历史与笔记

- 仅选文：只发送当前摘录和问题。
- 选文及上下文：发送选文所在页及相邻页；跨页选区包含所有涉及页的邻近上下文。
- 整篇文本：按阅读器页码提取全文；API 使用提取文本，网页可另外附上原文文件。文本超过 10 万字时提示缩小范围，不悄悄省略中间页。扫描文献无法提取文本时，可改用仅选文、网页附件或先做 OCR。

API 对话按文献、工具、接口地址和模型隔离；切换后不会把另一篇或另一模型的历史混入请求。每条完成回答保留选文、问题、附件与页码，支持编辑回答、选中部分保存、定位原选文。笔记正文与来源标记一起提交，重复点击不重复插入，同篇已有笔记和其他批注保留。

“新建对话”对 API 清空当前对话上下文，对网页解除当前工具的绑定；已经加入笔记的内容保留。此版本是 Windows 安装包；macOS 需单独适配、构建和验证，未提供 Mac 安装包。

## 验证范围与接口参考

开发验证使用隐藏 Tk 窗口、隔离文献库、模拟 API 和无头 MV3 网页夹具，覆盖六家网页的选文、上传、回存、复用；没有操作真实登录账号，也没有对真实付费接口发起测试。因此网页账号权限、实时 DOM 与真实模型可用性仍以用户自己的连接测试为准。

接口配置依据：[OpenAI Chat Completions](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)、[DeepSeek](https://api-docs.deepseek.com/)、[Gemini 兼容接口](https://ai.google.dev/gemini-api/docs/openai)、[千问百炼](https://help.aliyun.com/zh/model-studio/first-api-call-to-qwen)、[豆包火山方舟](https://api.volcengine.com/api-docs)、[Kimi](https://platform.kimi.com/docs/api/chat)。
