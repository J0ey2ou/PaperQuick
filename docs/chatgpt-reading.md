# 阅读时用 ChatGPT 讨论文献

此功能通过本机 Edge / Chrome 扩展连接 ChatGPT 网页版，使用你在浏览器里登录的 ChatGPT 账号，无需配置 API Key。需要将新版 `browser-extension` 文件夹加载到**默认浏览器**；已有扩展请在扩展管理页重新加载，并允许新增的 ChatGPT 与本机连接权限。软件要保持运行。

1. 在软件阅读页打开文献，选择文字，右键 **用 ChatGPT 讨论选中文字**。
2. 讨论图表时，点击工具栏 **框选图片供 ChatGPT 讨论**，或使用同名右键项。拖动矩形选择页面区域，松开后右键 **用 ChatGPT 讨论选框图片**。选框只裁剪已渲染的文档页面，不截取电脑屏幕。
3. 首次打开会在 ChatGPT 中准备正文附件与选区内容。检查文件上传是否完成，按需修改问题，再点击网页的发送按钮。软件不会替你发送。
4. 发送后，扩展保存这篇文献的普通对话地址。此后同篇文献的选区继续进入原对话；原标签页仍在时会复用它。正文没有改变且已确认发送过文件时，不再重复附上正文。每次选框图片仍会作为新的附件准备。

如果输入框已有草稿，扩展会保留草稿并提示；先发送或清空草稿，再点击提示中的重试。第一次消息尚未发送时，也请先完成它再选择下一段。对话和文件能否使用仍取决于当前登录账号及 ChatGPT 网页的上传状态。

**网页适配限制**：这是一项网页适配功能，没有使用未公开的 ChatGPT 接口。网页结构变化、登录验证、附件额度、网络故障或网页拒绝程序附加文件时，自动准备可能失败。提示支持重试；也可在网页手动附上相同正文文件，再重试选区。为限制本机传递占用，当前自动附加支持每个文件不超过 24 MB，正文支持 PDF、DOCX、TXT、Markdown；旧 DOC 请先转为 PDF / DOCX。该上限是本软件的限制，不代表 ChatGPT 账号额度。

绑定需要普通 `chatgpt.com/c/...` 对话；临时聊天、自定义 GPT 和项目专用路径尚未适配。对话删除、账号切换或无权访问时，在阅读区右键 **重新绑定这篇文献的 ChatGPT 对话**，下次重新创建。此操作保留网页原对话。首次消息发出后请等扩展提示绑定完成。

选区传递在本机临时保留 30 分钟，过期后从阅读页重新打开。正文、选区内容只在你主动点击 ChatGPT 讨论后提供给该网页；对话地址与正文校验信息保存在本地文献库，选区和传递凭证不会写入持久历史。正文和图片附到 ChatGPT 后适用该服务的账号与数据设置。

## 截图到笔记

工具栏 **截图到笔记** 会切换到十字光标。在文档页面内按下并拖出矩形，松开即可保存到笔记，随后恢复文字选择。支持反向拖动，拖出页面会限制在起始页边界，页外起拖和过小选框被忽略。Esc 取消；不会获取桌面截图或改动剪贴板。文本编辑视图请先返回分页阅读。

跨页选择文字后，右键 **插入选区截图到笔记** 会逐页裁剪选中文字所在区域，按页序拼成一张图片。右键点在选区的任一页都有效；页面移出缓存后会重新渲染，不会只保留第一页。长图保存时保留下方各页内容。
