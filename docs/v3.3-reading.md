# v3.3 阅读与整理升级

本版把选文件、阅读、图片笔记和文献关联放进同一条工作流程。安装包为 [PaperQuick-v3.3-Windows.zip](https://github.com/J0ey2ou/PaperQuick/releases/download/v3.3.0/PaperQuick-v3.3-Windows.zip)。升级前从托盘退出并备份原文件夹，覆盖程序文件时保留 `本地文献库`、`settings.json`、`shortcut.json`。

## 导入与撤回

在“文献分类”点击“导入文件夹”。扫描结束后会出现文件清单：点击第一列的勾选框决定是否导入，也可以搜索文件名、全选当前列表或全部取消。只有勾选的文件才会导入。确认后选择课题，原文件会保留。

“撤回导入”撤回最近一批导入，并恢复原有课题关联。导入后已阅读、编辑或新增笔记的文献会保留，避免丢失后续工作。撤回记录保存在本机，重新打开软件后仍可使用。

选择一篇或多篇文献，点击“删除文献”，也可以在列表右键删除。文献和归档副本移入恢复区；“恢复最近删除”可以找回它们。导入前的来源文件不会删除。

## 阅读空间与连续翻页

- 拖动正文和笔记之间的分隔线，调整两侧宽度。
- 点击“收起笔记”或“专注阅读”，给正文更多空间；专注模式用“返回完整阅读界面”退出。
- 默认勾选“连续阅读”，向下滚动就能接着看下一页。上一页、下一页、跳页仍可使用；取消勾选可恢复单页模式。
- 默认“选择文字”：像普通文档一样拖选文字，按 `Ctrl+C` 复制，也可以右键记笔记。需要拖动页面时选“拖动阅读”，或用鼠标中键拖动。
- PDF 必须有文字层才能选字。扫描图片页可截图或框选批注，本版没有 OCR。

## 图片笔记与截图

在笔记栏点击“插入图片”，选择本地图片。点击“截图到笔记”后，在阅读页面拖出一个框，松开即可插入截图；已选中文字的区域也可右键“插入选区截图到笔记”。截图和图片会随笔记自动保存。

如果图片已经在剪贴板中，在笔记框按 `Ctrl+V`，或右键“粘贴截图 / 图片”。普通文字粘贴仍然可用。

在右上角“设置 → 自定义研究笔记模板”填写自己的模板，保存后，阅读页的“研究笔记模板”按钮会插入该内容。“恢复默认模板”可以找回初始模板。

## 页内链接、标记与文献关联

在正文需要记录的位置右键：

| 操作 | 作用 |
| --- | --- |
| 添加阅读笔记 | 在笔记中插入页码，并在右键位置留下“笔”标记 |
| 在此处添加批注 | 为这个位置记录批注 |
| 关联已收集文献 | 从文献库中选择另一篇文献，留下可打开的关联标记 |
| 添加超链接 | 填写外部网址，或选择本地 PDF、Word、TXT；本地文档会收纳并关联 |

双击页内标记可以打开链接、跳到关联文献或定位笔记。文字阅读 / 编辑模式中的标记也可以单击打开。标记大小在“设置 → 阅读与笔记”中调整，范围为 8–48。

手动关联在图谱中显示为蓝线。引用关系、内容相似关系和手动关联分别显示，便于判断两篇文献为什么相连。

## 在阅读页查看参考文献

点击“嵌入参考文献”，参考文献会出现在工具栏右侧。也可以在独立参考文献窗口中右键“嵌入阅读页顶部”，切换回独立窗口则点击“独立窗口”。

在嵌入清单中双击一条参考文献，或右键“查找原文 / 下载归档”，会在阅读页上方打开查找窗口，正文仍留在原位置。先核对候选标题、作者和年份，再选择课题收藏、下载归档；该文献会与当前阅读文献建立引用关联。

右键“在阅读位置留下引用链接”，可以把一条参考文献留在正文最近一次右键的位置，之后双击标记继续查找。

本版修复 BMJ 常见的无“References”标题、跨行 DOI、年份被误识别为标号等问题。打开文献会重新提取；也可以在参考文献面板点击“刷新”。保留原文编号，带 `*` 的编号仍表示提取顺序，需要与原文核对。

## Word 原文编辑与原文件批注

打开 Word 后，点击阅读页“编辑原文”，即可在阅读框中修改文字。按 `Ctrl+S` 保存，然后返回分页阅读。保存更新文献库里的归档副本，并把上一版保存在文献库的 `versions` 文件夹；导入前的来源文件会保留。

编辑模式以文字为主，分页阅读用于查看版式。修改通过 Word 的文字范围保存，未编辑的图片、表格和批注保留；表格分隔符请保留，只修改单元格内容。此功能需要本机安装桌面版 Microsoft Word。

Word 原文件批注和 PDF 原文件批注会显示在“高亮 / 批注”清单中，并可打开查看。Word 预览会包含批注信息。软件新建的笔记和批注保存在本机；原文件自带的批注在阅读页查看，需要修改它们时使用原文工具。

## TXT 与笔记导出

可以导入和阅读 TXT、Markdown，支持 UTF-8、UTF-16 和常用中文编码。文字可选取，TXT 也可在阅读框中编辑，按 `Ctrl+S` 保存归档副本。

导出笔记可选择：

- 网页笔记：图片嵌在文件中，适合分享和查看。
- Markdown：图片放在旁边的 `.assets` 文件夹，请一起保留。
- TXT：保留文字、批注及图片位置说明。

导出时会记录对应的文献和阅读文件，并自动把结果关联为该文献的“笔记”附件。图谱中金色方块表示导出的笔记，连线指向对应文献；点击后可回到该文献的阅读笔记。

## English

v3.3 is a reading and organisation update for the local Windows workspace. Download [PaperQuick-v3.3-Windows.zip](https://github.com/J0ey2ou/PaperQuick/releases/download/v3.3.0/PaperQuick-v3.3-Windows.zip). Exit from the tray and back up before upgrading; retain your library and settings. Folder import now offers checkboxes before copying files, with durable undo for the latest batch. Papers can be removed and recovered while their original source files stay intact.

The reader supports continuous pages, PDF text selection, focus mode, adjustable panes, images and reading-area screenshots in notes. Right-click a passage to add a note, link a collected paper, or create a local-document / web link. Position markers have a configurable size, and note templates can be changed in Settings.

References can be docked above the reader. A lookup window finds full-text links and collects a reference without replacing the reading page. BMJ bibliography extraction now handles missing headings and wrapped DOIs.

Word text can be edited inside the reader using desktop Microsoft Word. Saving updates the managed copy and retains the previous version; source files stay unchanged. Original Word and PDF comments are visible. TXT / Markdown reading and TXT editing are also supported.

Exported notes are attached to their source paper with the “note” role. HTML includes embedded images; Markdown uses an adjacent assets folder. The graph displays exported notes and manually linked papers. Scanned PDFs still require a text layer for text selection; OCR is not included.
