# v3.4 · 单行阅读工具与自动保存

主阅读区、附件比对区和笔记区的工具改为单行图标，把更多空间留给正文和笔记。鼠标停在图标上片刻即可看到操作说明；窗口较窄时，右端“···”收纳剩余工具。所有原有操作仍然可用。页码输入框保留，输入后按回车跳页；当前工具和连续阅读状态有底色提示。

设置中的皮肤、快捷键、邮箱、阅读方式、标记大小和笔记模板修改后会自动保存，短暂停止输入即可。切换页面、收起到托盘或退出时会再次保存尚未写入的修改。填写不完整的项目会提示原因并保留原来的有效值；其他有效设置仍会保存。

运行中的全局选词助手会读取新快捷键。若助手尚未启动，点击“保存并启用快捷键”。设置底部的“关于文献直达”显示版本号、开发者和项目链接。

## 完整升级并继承文献库

本版提供 **PaperQuick-v3.4-Windows.zip** 完整包，包含主程序、全局选词助手、浏览器扩展、引用样式和使用说明，保留此前查询、归档、EndNote 交换、阅读批注、附件比对、图谱和 Word 引用等功能，也包含当前的琉璃皮肤、最近阅读、图谱分组和显示名称整理改进。

1. 下载并解压到一个临时文件夹。
2. 等当前工作完成后，由你从托盘退出软件和选词助手。先备份原程序文件夹，尤其是完整的“本地文献库”。
3. 将新包内文件复制到原程序目录，覆盖同名程序文件。**保留原目录中的“本地文献库”、settings.json、shortcut.json**。新包不包含这些个人数据，因此不会提供一个空库来替换它们。
4. 从原目录运行“文献直达.exe”。文献、附件、笔记、课题、阅读记录和设置会继续从原目录读取。

如果选择换一个安装目录，请在软件退出后，把完整“本地文献库”、settings.json 和 shortcut.json 一起复制过去，再启动新版本。不要只搬数据库文件，否则正文、附件和图片笔记可能找不到。

构建不会主动退出、替换或启动正在使用的程序。本地新构建保存在独立版本目录，等你方便时更新。Word 编辑、分页预览和 Word 引用仍需要桌面版 Microsoft Word。

## English

v3.4 puts reader, attachment-comparison and note actions in a single icon row. Hover for descriptions; narrow panes retain all actions in the overflow menu. Enter a page number and press Return to jump.

Settings now save automatically and flush pending changes when leaving Settings, hiding to the tray or exiting. Invalid fields keep their previous valid values. About shows the version, developer and project link.

This is a complete Windows package, retaining earlier features. After you exit the app and helper, back up the old folder, then copy the new program files into it. Keep the entire `本地文献库` folder, `settings.json` and `shortcut.json`. If moving to a different folder, copy all of them while the app is closed. The package contains no personal library or settings. Builds run background checks and never stop or launch your installed application.
