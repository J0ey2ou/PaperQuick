# v3.5.0：标签归类、阅读引用与软件内更新

## 标签和课题

文献标签与作者关键词分开保存。右键“编辑标签”可批量设置；列表支持标签、阅读状态和评分筛选，也可以直接搜索标签。

选择左侧父课题，点击“新建子课题”。父课题显示自身和全部子课题中的文献，重复归类只显示一次。选择课题或子课题，再点击“标签自动归类规则”，输入用分号分隔的标签；文献匹配任意一个标签即加入对应课题，可以同时加入多个课题。

规则会立即应用到现有文献，以后新增或修改标签也会自动归类。移除标签或规则时，仅撤回自动加入的分类，手动分配和主课题保留。标签归类不移动正文文件；需要改变正文归档位置时，请使用“分配课题”并明确选择设为主课题。

## 阅读状态、评分和文件位置

状态包括未读、在读、已读、待读和搁置；评分为 1–5 星，0 表示未评分。文献列表和阅读页右键菜单均可设置。首次打开未读或待读文献时改为在读，已读状态不因再次打开而改变。

右键“打开已下载原文所在位置”打开当前正文的本机归档文件夹。正文缺失或尚未下载时显示具体原因。

显示名称和归档文件名生成时，缺失或未识别的作者、年份、期刊、DOI 等字段直接跳过，并清理多余分隔符；不会填入“未知作者 / 未知年份”。显示名称编辑仍不改动附件文件名。全部命名字段为空时保留可用标题或使用“未命名文献”。

## 引用与 Word

编号格式的正文 `[1]` 是引文标记，完整文献信息位于参考文献表。新版默认勾选“自动补齐文末参考文献”：首次插入正文引文时同步在文末生成完整列表，后续插入、删除、切换格式会更新已有列表；“更新全部引用”也会补齐原先缺失的表。可以取消勾选，保留手动放置列表的工作方式。

Word 引用组件需随完整包一起更新，旧组件不能静默忽略新的文末列表操作。修改保持在打开的 Word 文档内，用户正常保存；一次操作可整体撤销。只操作文献直达的引用域，不改写其他软件的引用。

阅读页右键新增“插入引用到笔记（自动页码）”和“插入 Word 引用（自动页码）”。跨页选区带入起止页码；未选中文字时采用右键所在页。页码按阅读器页面计数，可以在插入前按文章印刷页码修正。Word 仍需要用户确认目标文档、光标和引用格式后插入。

## ChatGPT 通篇解读

第一次单篇导入成功后显示解读模板窗口；批量导入或后续使用时，可右键文献或在阅读页选择“ChatGPT 通篇解读 / 修改模板”。模板包括研究问题、内容、方法、结果、局限和精读顺序，可以修改并保存为自己的默认模板。设置页也提供模板编辑入口。

点击“上传文献并打开 ChatGPT”才进入本机连接页，由浏览器扩展上传正文并把 Prompt 填入输入框，不自动发送，不在软件内生成 AI 回复。正文已在绑定对话发送且未改变时继续复用。同一篇文献随后可选词、选图逐步讨论。

需使用浏览器扩展 2.4.2 或更新版本。网页改版、账号权限、网络及附件额度仍可能影响适配；真实账号上传和真实 Word 操作未纳入本版后台测试。

## 设置内检查和安装更新

当前版本开始，在设置的“软件更新”中点击“检查更新”，查看 GitHub 更新说明，再点击“下载并在退出后更新”。可选“启动时检查更新”和“接收预览版”。默认只检查正式发布，不下载源码分支中的未发布改动。

下载会校验发布资产的 SHA256、包内版本和公开文件清单。正常从托盘退出主程序与选词助手后，隐藏更新组件替换程序文件；不会替你强制关闭正在使用的程序，也不自动弹出新窗口。下一次启动使用新版。安装失败会回滚已替换文件；下载与备份保存在安装目录的 `.updates` 中，以便重试和排查。

完整“本地文献库”、`settings.json`、`shortcut.json` 以及安装目录中的其他个人文件都不在更新覆盖范围内。更新浏览器扩展文件后仍需在扩展管理页重新加载，并刷新已有 ChatGPT 标签页。

v3.4.x 尚无此内置更新入口，需要先安装一次 v3.5.0 完整包；以后使用设置内更新即可。升级到当前版本后，主界面提示新版本及主要改动。

## 后续发布约定

每个发布使用精确版本号 `vX.Y.Z`，上传 `PaperQuick-vX.Y.Z-Windows.zip`、`SHA256SUMS.txt` 和更新说明。ZIP 内部根目录同名，包含 `version.json` 与 schema 1 的 `update-manifest.json`。`scripts/package_release.py` 会生成这些文件；正式版设为 GitHub 最新发布，预览版保留预览标记。

更新器读取 [GitHub 官方 Releases 接口](https://docs.github.com/en/rest/releases/releases)，从固定的 `J0ey2ou/PaperQuick` 发布地址下载资产。此约定也已记录到项目 `AGENTS.md`，后续版本需持续兼容。
