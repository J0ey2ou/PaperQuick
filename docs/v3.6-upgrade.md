# v3.6.0 使用与升级说明

## 回复存回文献

在扩展管理页重新加载 `browser-extension`，再刷新原 ChatGPT 标签页。从阅读器讨论选区或通篇解读，核对附件和 Prompt 后自行发送。已绑定对话的回复下出现“存为文献批注”；点击后保存该条回复到原讨论的正文附件、页码与选区，在阅读器“高亮 / 批注”中自动出现。同一回复重复回存会去重。

通篇解读默认回存第一页，选区讨论回存对应位置；不会自动发送问题或自动保存所有聊天。保持桌面程序运行；本次运行内回存连接最长有效 24 小时。重启、连接过期或正文替换后，请从阅读器重新连接。单条回复最多 10 万字，真实网页改版可能需要后续适配。

## 跨文献位置链接与 PDF 导出

在目标 PDF 的具体位置右键“记住此处作为文献链接目标”，再打开来源 PDF，右键“在此处插入已记住的位置链接”。双击页内标记可跳到目标原附件、页码和页内位置。“关联已收集文献”也支持填写目标页码和纵向百分比。

标记日常保存在本地文献库，原 PDF 保留。右键“导出带批注和位置链接的 PDF 副本”，可把回复写为原生弹出批注，把文献位置写为 GoToR 链接。链接指向本机目标 PDF；目标文件移动后需重新导出，其他阅读器能否打开由其设置决定。

## 标签、界面与导入

编辑标签可勾选已有标签或输入新标签。左栏“标签管理”统一重命名、合并同名标签或删除标签，同时更新自动归类规则，保留文献与手动分类。

新增书页白主题，调整冰川蓝和鸢尾紫；筛选并入列表标题行，窄窗自动换行，按钮也随宽度换行。表头按字体实测最小宽度，长表提供横向滚动，行高适配 DPI；设置、表单、总结页可以在子控件区域滚动。

阅读页导入后通知已有列表，切回列表时再次刷新。批量导入完成后定位本批条目；“导入记录”显示每个文件的成功、关联、失败、耗时和错误。完成回调异常不会停止后续任务轮询。列表改为轻量字段、批量附件查询和 160ms 搜索防抖，导入仅为涉及的条目记录撤回快照。

## 更新

设置 → 检查更新 → 下载并在退出后更新，正常退出后安装，下次启动生效。保留完整本地文献库、settings.json 和 shortcut.json，不强制结束运行程序。扩展文件更新后需要重新加载扩展。
