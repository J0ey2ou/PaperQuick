# v3.6.1 修复说明

## 成功导入但没有独立条目

部分 PDF 将 `10.1136/bmjopen-2012-002007` 换行为前缀和最后一段数字。旧版本可能仅识别共同前缀 `10.1136/bmjopen-2012-`，误把不同文章合并为同一条目的正文和附件，而自定义显示名仍显示原文章。

本版恢复跨行 DOI，禁止用不完整前缀去重。再次导入受影响文件时，会检查归档正文与附件的完整 DOI；只有文件校验一致、两个 DOI 明确不同且记录符合旧截断特征时才拆分恢复。原记录快照保存在本地配置，正文文件保留，原笔记与自定义名称保留，仅随附件移动其明确关联的批注；未明确归属的笔记留在原条目。恢复记录不会被“撤回导入”删除。

## ChatGPT 上传

扩展更新为 2.5.1，需要在扩展管理页重新加载，然后刷新 ChatGPT 页面。新版处理输入框重建、文件控件未接收、本地分块短暂失败和慢上传，并等待附件状态真正完成。网页明确报告失败时不会自动反复提交或发送消息，草稿会保留；按提示检查额度或移除失败附件后再重试。

已绑定对话的旧附件失效时，从阅读器右键选择“重新上传正文到当前 ChatGPT 对话”，可保留原对话重新附上正文，无需重建聊天。

## 阅读缩放与更新

正文和附件比对页中按 Ctrl 滚动滚轮可缩放，普通滚轮继续滚动。缩放会合并快速输入，并尽量保持鼠标指向的页内位置。

设置 → 检查更新 → 下载并在退出后更新。原文献库、设置和快捷键配置保留；不强制关闭运行中的程序。
