# PaperQuick v3.8.0 · 内嵌聊天与列标题筛选（2026-10-21）

- Windows 阅读器新增“内嵌网页”，聊天页面直接显示在右侧页签，复用同篇对话、填入选文和准备正文，回答可回存 AI 页签再加入笔记。API 与外部网页模式保留；按钮文字随模式调整。
- 内嵌使用独立 WebView2 配置，首次在软件内登录；不复制外部浏览器 Cookie。某些网站或 Google OAuth 可能拒绝内嵌登录，保留“在浏览器中打开”入口，不绕过网站限制。Mac 当前仍使用 API / 外部网页。
- 文献列表移除独立状态、评分和标签筛选栏。每列点击标题文字排序，点击 ▾ 筛选；支持多选值和包含文字、组合筛选及清除筛选，显示筛选标记与结果数。年份与评分按数字排序，未知年份始终放后。
- 控件更新为圆角按钮、轻描边输入框、简洁下拉箭头、无箭头细滚动条和圆形滑块；跟随明暗主题保留键盘焦点、悬停和禁用状态。
- 导入完成自动清除列筛选并定位新条目，避免新导入被旧视图条件隐藏；表头保留高 DPI 测宽及横向滚动。
- 312 项后台回归中 309 项通过、3 项真实 Word 集成跳过。后台验证包含真实 WebView2 隐藏子控件与隔离网页：选文、附件、回存、绑定复用和未发送草稿保护；不操作真实账号、不做桌面输入或截图。设置内 GitHub 更新、退出后安装及个人数据保留约定不变。

阅读器选文右键 → 询问 AI → 模式选“内嵌网页” → 在此打开聊天。回存回答后点击“回答 / 笔记”，可保存整条或选中部分。

列标题文字与箭头分别负责排序、筛选；可拖动列分隔线改宽。原有搜索与课题范围仍有效。
