# PaperQuick v3.8.2 · 内嵌网页原生渲染修复（2026-10-21）

- 内嵌聊天改为 WebView2 Core 控制器直接托管到阅读面板的原生子窗口，移除 WinForms Form/Control 包装层；统一系统 DPI，并使用兼容软件渲染，修复网页可执行但渲染子窗口未正常建立的灰屏路径。
- 页签隐藏、恢复、主窗口移动及面板缩放均同步浏览器可见状态、位置和边界；“重新显示”收到组件确认后才反馈状态，保留当前网页、草稿和附件。
- 增加网页加载失败、渲染进程异常和组件退出提示，避免空白区一直显示成功。新增本机限量显示诊断记录，只保留窗口状态、尺寸与渲染模式，不记录文献、提问、回答、会话地址或接入令牌。
- 后台回归扩展到 Core 控制器与网页可见状态；新增独立 Windows 桌面中的真实 Notebook 页签切换、偏移位置、原生渲染可见链、上传回存与复用检查，不切换用户桌面，不截图或模拟输入。
- 313 项后台回归中 310 项通过、3 项真实 Word 集成跳过；另有 ChatGPT / DeepSeek 两个独立桌面场景通过，真实账号未操作。
- 设置内 GitHub Releases 自动更新入口、SHA256 校验与正常退出后安装保持有效，保留文献库、设置和内嵌网页登录配置。真实 AI 账号未操作；Mac 继续使用网页账号 / API。

正常退出旧版本并重新打开后，在 AI 阅读选择“内嵌网页”。新的显示恢复只同步控制器，不刷新页面；网站拒绝内嵌登录时仍可用浏览器入口。显示诊断位于 runtime/embedded-chat/display-diagnostics.jsonl，仅保存有限的显示状态。
