# PaperQuick v3.8.4 · 课题一键打包（2026-10-22）

在文献分类左侧选中课题，点击课题标题旁的 **打包课题**。弹窗默认勾选该课题及所有子课题的文献，不受列表搜索和筛选影响。可以取消整篇文献，也可以展开文献后取消单个正文或补充附件。全部文献视图中的入口为 **打包全部**，弹窗内可以重新选择范围。

选择 **ZIP 压缩包** 或 **文件夹**，填写保存位置和打包名称，然后点击 **开始打包**。保存位置应位于文献库之外；同名输出会自动编号。每篇文献单独存放，附文献目录和文件清单；尚未下载的文献保留目录记录，缺失文件明确标记，网址只保存地址。此包用于分享文件，不包含完整阅读笔记和数据库，完整备份仍需在正常退出后复制整个文献库。

打包在后台执行，显示文件大小和进度；可取消，未完成的输出会清理。文献分类的课题导航可滚动，低频操作收进 **文献库工具 / 课题与标签管理 / 更多操作**，底部显示所选篇数，详情支持展开与收起。

已安装支持自动更新的版本，可在 **设置 → 软件更新 → 检查更新 / 下载并在退出后更新** 获取本版。仅在正常退出后安装，不强制关闭主程序、选词助手或 Word。保留原目录完整的 `本地文献库`、`settings.json`、`shortcut.json` 与网页登录配置；替换失败会回滚。首次安装可下载 `PaperQuick-v3.8.4-Windows.zip` 并完整解压。

所有验证使用临时文献库与隐藏窗口，不操作真实文献、剪贴板、鼠标或键盘，不启动全局选词助手。
