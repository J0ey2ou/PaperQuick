# PaperQuick v3.8.5 · 图标居中与新增皮肤（2026-10-22）

阅读、笔记和附件工具栏的图标现在位于方形按钮正中，按钮之间保留清楚间距，并随 DPI 放大。当前工具有明确的选中边框，窄窗口中通过「更多工具」继续使用收起的功能。

在 **设置 → 界面皮肤** 选择「奶油暖砂」「雾松绿」「暮色玫瑰」「夜读黑」，或继续使用原有 11 套主题。下方显示阅读文字与配色色卡；选择后立即应用并自动保存，下次启动继续使用。所有主题窗口保持完全不透明。

本版同时统一导航、按钮、输入框和下拉菜单的留白与交互状态，修复搜索结果、图谱刷新时回到旧配色的问题，以及文献分类工具条在窄窗口被裁切的问题。

已安装版本可在 **设置 → 软件更新 → 检查更新 / 下载并在退出后更新** 获取本版。仅在正常退出后安装，不强制关闭主程序、选词助手或 Word。保留完整 `本地文献库`、`settings.json`、`shortcut.json` 与网页登录配置；替换失败回滚。首次安装下载 `PaperQuick-v3.8.5-Windows.zip` 并完整解压。

本次只进行后台、隐藏窗口与隔离验证，不截图、不模拟输入或修改剪贴板。
