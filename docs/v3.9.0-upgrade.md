# v3.9.0：研究工作台与前三批优化

本版将日常文献整理、证据提取和研究输出接入同一文献库。原有查询、阅读、课题打包、Word 引用及 15 套主题继续保留。

## 从哪里开始

1. 顶部进入 **研究工作台**，选择课题，填写研究问题、待办；在文献列表右键将文献加入该课题阅读队列。点击 **继续阅读** 恢复最近文献的附件、位置、缩放及布局。
2. **文献分类 → 智能视图** 保存当前课题、列筛选、排序与显示列；视图保存条件，新文献会自动参与匹配。
3. **研究工作台 → 全文检索 / OCR** 先建立本地索引。PDF 按实际页码检索，Word/TXT 按逻辑段落定位；覆盖列表明确显示尚未索引、扫描/空白页、文件变化及缺失。
4. 阅读器 **文内查找** 搜索当前附件；**加入证据卡** 把选中的原文与来源交给研究卡编辑器，填写自己的解释、论点与支持/反对立场，核对后再标记。
5. **证据与写作** 管理证据卡、比较矩阵、综述提纲、两阶段筛选和引用审计；矩阵导出 CSV，提纲导出 Markdown 或 Word，筛选统计可导出供继续整理。

## 备份与后台任务

**设置 → 备份 / 恢复 / 任务中心** 或工作台 **备份 / 任务** 可创建完整文献库 ZIP。备份使用 SQLite 一致性快照与逐文件 SHA256，包含正文、附件、笔记、阅读记录及研究数据。文件或数据库在备份过程中改变时拒绝发布不一致结果，可在任务中心重试。

恢复先校验清单，只写入新的目录，保留当前库。点击 **使用恢复的文献库** 后，下次正常启动使用该目录；也可在设置选择其他已有文献库。私人完整备份包含库内配置，课题交接包则仅携带白名单资料。

任务中心显示进度、失败原因、取消及重试。重启后的未完成任务标为中断；支持重建的任务可重新执行。旧导入/归档任务需要完整执行，不能在文件修改中途强行取消，也不会盲目重试。

## 本地 OCR

OCR 为可选功能。配置本机 Tesseract 可执行文件及已安装的语言数据后，对扫描页面运行识别。软件不自动下载 OCR 引擎或语言包，不把文献上传到 OCR 云服务。索引记录 OCR 来源，保留原始文件；识别结果仍需人工核对。DOC 请先转换成 DOCX 或 PDF。

## 跨文献 AI

在 **跨文献 AI** 选择课题及文献，填写检索关键词，在本地索引中选择命中片段，再填写研究问题。发送预览完整展示会发出的摘录范围；长页只发送所显示的摘录。只有点击发送才调用你在 **API 设置** 中配置的服务。

回复需要带来源编号及连续原文引文。程序核对编号、引文和来源文件是否变化，校验失败不会保存为已校验记录。通过校验只表示引文与所选原文相符，不能证明模型解释或结论正确。问题超出选文范围时需要补充文献或缩小问题；不自动进行额外付费请求。

## 完整课题交接

工作台 **课题交接** 打包课题子树、附件、笔记/批注、关系、研究证据、矩阵、提纲、筛选和课题工作台。跨课题证据所需的来源文献会单独带入，其所在课题的其他无关文献不会跟随导出。不会携带 API 密钥及 AI 账号配置。

导入前显示包内内容、同 DOI/同附件重复以及缺失来源。导入到新的文献库并保留每条记录，不自动合并可能不同的版本。研究证据的导入核对状态需在接收方重新确认。原来的 **打包课题 → ZIP / 文件夹** 继续用于只分享文献文件。

AI 独立对话历史不随课题交接；已整理到笔记、证据卡和提纲的内容随包保留。完整私人备份会保留库内的对话历史。

## 安装与更新

使用设置内的 **检查更新 / 下载并在退出后更新**。更新入口继续连接 `J0ey2ou/PaperQuick` 最新正式版；正常退出后替换程序，保留文献库、设置和快捷键，替换失败可回滚。程序占用时保留新构建，不强制关闭软件、选词助手或 Word。

手动下载的完整包为 `PaperQuick-v3.9.0-Windows.zip`，内部根目录 `PaperQuick-v3.9.0/`，包含 `version.json` 和 `update-manifest.json`，配有 `SHA256SUMS.txt` 与公开 `update.json`。

本版未引入团队多人同步、移动端或双人系统综述。两阶段筛选为本地单人工作记录，完整系统综述所需的研究登记、跨数据库去重及 PRISMA 最终报告仍需研究者审核整理。
