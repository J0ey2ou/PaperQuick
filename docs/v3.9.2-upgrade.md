# PaperQuick v3.9.2 正式版使用与升级

本版改善窄栏与多阅读页切换、文献读取和检索速度，并新增阅读分享。

## 阅读与链接

笔记侧栏较窄时，标签自动变为完整页面选择器；拉宽后恢复标签。聊天、AI、目录与翻译操作自动换行。聊天网页只在所属页面可见时显示。

附件比对区采用紧凑布局：顶部切换附件、编辑或收起，下方为常用阅读工具与正文。重复的大标题、打开文献和最近阅读入口移除；不允许在附件里再次嵌套比对。附件独立翻页和缩放，首次按分栏宽度适配；笔记默认收起，展开后使用上下分栏以保留正文宽度。全文查找、证据与其他操作继续通过工具及右键菜单使用。

聊天回复中的普通网页链接由用户点击后交默认浏览器打开，当前聊天保留。程序自动弹窗继续拦截，登录弹窗按提示使用“在浏览器中打开”。API 回答的 HTTP(S) 链接也可点击。

## 分享

- 阅读总结 → 阅读回顾 → 分享阅读回顾：按所选时间与课题生成汇总卡片，每张最多四篇，自动分页。
- 阅读总结选中文献 → 分享选中文献，或阅读器工具条 → 分享这篇文献：生成单篇卡片。
- 可选「书页花园」「静夜书海」，选择是否包含摘要、阅读时长、个人笔记与摘录，填写寄语后预览。
- 笔记与摘录默认关闭；导出仅包含选择的文字与插画，不包含附件、文件路径、账号或密钥。长文字使用带省略号的节选。
- 保存为 PNG；多页自动使用编号后缀，已有同名文件不会被覆盖。不会自动发送到社交平台或改动剪贴板。

## 性能与数据

旧库首次打开会建立轻量摘要投影与查询索引，需要扫描一次现有元数据；原始正文、笔记和附件保留。后续读取列表和当前文献搜索不再依赖全文体积。

PDF 缓存按文件版本失效，并限制内存和待处理页数。修改或替换原文件后如提示版本已变化，请重新打开。导入仍校验内容完整性；新日志和旧日志都可撤销。

设置保存会保留有效备份；损坏原件隔离保留。无有效备份时不会覆盖损坏文件，界面给出提示。任务历史分页显示，更新设置显示最近安装结果。

## 升级

完整包名称为 `PaperQuick-v3.9.2-Windows.zip`，根目录为 `PaperQuick-v3.9.2/`。保留完整 `本地文献库`、`settings.json`、`settings.json.bak`、`shortcut.json` 等个人数据。待主程序和选词助手正常退出后再替换，不强制结束主程序、助手或 Word。

优先使用设置内“检查更新 / 下载并在退出后更新”，自动更新继续连接 `J0ey2ou/PaperQuick` 的 GitHub Releases，校验下载包后在正常退出时安装。手动下载可前往 [v3.9.2 发布页](https://github.com/J0ey2ou/PaperQuick/releases/tag/v3.9.2)，使用附带的 `SHA256SUMS.txt` 核对完整包。

验证使用后台、隐藏窗口、隔离桌面和临时文献库；已完成原生组件编译、冻结程序自检，以及 ChatGPT / DeepSeek 本地模拟页面的 WebView2 显示、切页、缩放和草稿保护、上传回存与复用验收。真实平台账号和登录流程仍取决于本机及服务商环境，未纳入自动验收。
