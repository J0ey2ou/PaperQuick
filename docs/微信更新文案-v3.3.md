# 文献直达 v3.3：读论文、做笔记，终于可以连起来了

你有没有遇到过：文件夹里攒了很多论文，导入时却只能一股脑全放进去？读到关键图表，截图、写笔记、找参考文献又要在几个窗口里来回切换？过段时间找到那份笔记，却忘了它对应哪篇文章？

这次文献直达 v3.3，围绕这些阅读和整理中的小麻烦，做了一轮更新。

**① 导入前先挑选，整理时可以后悔**

导入文件夹会先列出文件清单，勾选真正需要的文献再导入。导错一批，可以撤回；文献分类新增删除与恢复，方便清理不需要的条目。来源文件保留，撤回时也会保留后来已阅读、编辑或添加笔记的文献。

**② 阅读空间更自由，翻页和选字更顺手**

正文与笔记的宽度可以拖动调整，也可以收起笔记、进入专注阅读。支持连续翻页，向下滚动就能接着读；有文字层的 PDF 可以直接拖选、复制，再右键记笔记。新增 TXT、Markdown 阅读，TXT 可直接修改；Word 也可以在阅读框切换到文字编辑，保存到文献库副本，并保留上一版本。

**③ 关键图表，随手放进笔记**

笔记支持插入图片、粘贴剪贴板截图，也可以直接框选阅读区域，把图表截进笔记。研究笔记模板可以在设置里自定义：研究问题、方法、结果、局限，按自己的习惯记录。图片与文字一起保存在本机。

**④ 在读到的位置，留下下一步的线索**

正文右键可以记笔记、关联已收藏文献，或添加本地文件、外部网址链接。操作位置会留下可点击的标记，之后能回到笔记、打开相关文献或继续访问链接；标记大小也能自己调整。让两篇论文之间的联系，留在你发现它的地方。

**⑤ 参考文献留在阅读页，查原文少切一个窗口**

参考文献清单现在可以嵌入阅读页顶部，保留能识别出的原始标号。选中一条即可查找原文、选择课题收藏和下载归档，正文仍留在原位置；也可以把引用链接放到阅读位置。

本版同时修复了 BMJ 文献中部分参考文献提取失败的问题，包括缺少参考文献标题、跨行 DOI、年份被误当成编号等情况。原 Word 和 PDF 文件中的批注也可以在阅读页查看。

**⑥ 笔记有出处，图谱也能看见它**

导出笔记后，软件会自动把它关联到对应文献和阅读文件，标注为“笔记”附件。支持带图片的网页笔记、Markdown 和 TXT。图谱新增金色笔记节点，也能显示手动关联的文献：从一篇论文，到相关论文，再到自己的笔记，线索更容易找回来。

这次更新的重点很简单：把选文件、读原文、记图表、查引用和回看笔记，放进更连贯的流程里。

Windows 10 / 11 64 位，解压即可使用。上述本地整理和阅读功能不需要外部 AI 或 AI API Key。Word 编辑和分页预览需要安装桌面版 Microsoft Word；扫描 PDF 没有文字层时仍需截图记录，本版不含 OCR。参考文献提取后请核对，全文下载仍取决于开放情况和访问权限。
