选中文字，快速到原文

2.3 版：浏览器使用原生右键菜单；Word、PDF、微信电脑版使用全局快捷键。全局助手只驻留托盘，不显示鼠标跟随浮窗。

Word / PDF / 微信：开启全局快捷键

  1. 打开 文献直达.exe，点击右上角 全局快捷键；或者双击同目录的 全局选词助手.exe。
  2. 在原软件里选中论文标题、DOI 或文献引用段落。
  3. 按软件显示的快捷键。默认 Ctrl + Alt + F，占用时自动换成 Ctrl + Alt + Shift + F 或 Ctrl + Alt + F8。软件会自动查询，匹配明确时打开原文网站；有多个候选时显示结果供核对。

状态栏和托盘菜单显示当前快捷键。助手驻留系统托盘；右键托盘图标可退出助手。关闭文献直达主窗口不会关闭助手。

快捷键触发后，助手等待按键松开再复制当前选中文字。只有剪贴板确实出现新文字时才查询，不会用旧剪贴板内容。此时剪贴板会变为刚复制的文字。不记录历史，不监听鼠标，不自启动。扫描版 PDF 需要 OCR，管理员权限窗口或禁复制的内容可能无法读取。

自定义快捷键

主界面点击“设置”，在输入框按下组合键或手动填写（例如 Ctrl + Alt + J），再点击“保存并启用”。也可右键托盘图标 → 自定义快捷键 → 按键 → 保存。至少两个修饰键（Ctrl / Alt / Shift）+ 字母、数字或 F1–F24。设置立即生效、下次启动保留；被占用时以状态栏和托盘显示的实际组合为准。

Edge / Chrome：安装原生右键菜单

浏览器扩展独立工作，无需先启动桌面软件。仅需设置一次：

  1. 在浏览器地址栏打开 edge://extensions 或 chrome://extensions。
  2. 开启 开发人员模式 / 开发者模式。
  3. 点击 加载解压缩的扩展 / 加载已解压的扩展程序。
  4. 选择软件包里的 browser-extension 文件夹：默认在 D:\文献打包自动化\browser-extension。
  5. 选中英文论文标题或 DOI，右键选择 文献直达 → 查找文献并打开原文。没有选词时，右键选择 查找当前页面中的论文，或点击工具栏的文献直达图标。

从旧版更新后，请在扩展管理页点击文献直达的“重新加载”，再重新发起查询。

请保留扩展文件夹。浏览器受单位策略管理时可能不能加载本地扩展，仍可使用全局选词助手。浏览器会提示扩展所需权限：文献接口访问、右键菜单和主动点击后的当前页读取。扩展没有后台抓取全部网页，不保存查询历史。

公众号出现“要求验证”怎么继续

  1. 在桌面软件中点击 在浏览器打开推送。
  2. 在浏览器里完成公众号要求的验证，确保正文已经显示。
  3. 选中正文里的英文论文标题 / DOI，按 Ctrl + Alt + F 查询；安装浏览器扩展后，也可以直接右键 查找当前页面中的论文。

浏览器扩展读取当前页面已经显示的正文，不跳过验证码或登录。中文新闻标题只作为检索线索；有多个参考文献时请核对标题和作者。

速度与自动打开

DOI 查询立即打开出版社入口；arXiv 编号立即打开 PDF。标题查询先显示候选，再补充原文，匹配明确时优先打开开放 PDF、全文页或出版社入口。结果陆续显示，不用等所有接口完成。也可点击“直接学术搜索”，将当前标题带入 Google Scholar。

只有单个 DOI、arXiv 编号或唯一完全匹配的英文标题才会自动打开；相似或同名论文展示候选。开放版本可能是预印本或作者稿，付费论文仍可能需要学校 / 机构权限。

查询的标题 / DOI 会发送到 Crossref、Europe PMC、arXiv、Semantic Scholar；可选 Unpaywall 邮箱随查询发送到该服务。软件不会自动保存论文文件。
