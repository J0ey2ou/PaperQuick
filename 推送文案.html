从收到论文到读懂、记住：我把文献查询做成了一个本地科研工作区

导师发来一个论文标题，合作者转来一篇公众号推送。你复制标题、打开搜索、核对作者、寻找全文、下载 PDF，再把文件拖进课题文件夹。读到一半想记个想法，又打开笔记软件；第二天回头看，却很难说清昨天读了什么、花了多少时间。

这些步骤单独看都不难，重复起来却很耗精力。我做了 文献直达 · PaperQuick 3.1，把它们接进一个 Windows 本地工作区：查找 → 下载归档 → 课题分类 → 阅读批注 → 关系图谱 → 阅读回顾。

目标很具体：少复制几次，少切几个窗口，让论文、笔记和阅读记录留在同一个地方。无需安装 Python，无需注册账号，本地整理与图谱不调用外部 AI，也不需要 AI API Key。

01｜导师发来一个标题，顺手就能找原文

支持完整英文论文标题、DOI、arXiv 编号 / 链接，以及可以读取正文的科研推送链接。结果逐步展示标题、作者、年份、DOI 和开放全文 / PDF / 出版社入口，方便确认是不是你要找的论文。

  • 复制粘贴：打开文献查询，点“粘贴并查找”，或粘贴后按 Ctrl + Enter。
  • Word / PDF / 微信电脑版：启动全局选词助手，选中文字后按自定义快捷键，例如 Ctrl + Alt + J。
  • Edge / Chrome 网页：装好随包扩展，选中标题或 DOI，右键“查找文献并打开原文”。也可查询当前推送页面。

单个 DOI、arXiv 有明确入口时先打开；标题匹配明确时可以自动打开。服务较慢时，“直接学术搜索”自动把当前内容带到 Google Scholar，省去重新复制。原生桌面应用使用快捷键，浏览器内使用扩展右键。

02｜找到原文以后，顺便把它放对地方

点击结果中的 “收藏 / 下载归档”，选择课题，没有课题就新建。找到可直接下载的 PDF 时自动保存并按规则命名；需要出版社网页操作时，打开对应全文入口。

文献分类列表右键提供两个清楚的入口：“下载原文（打开下载页面）” 用浏览器打开对应页面；“下载并自动归档” 查找开放版本并整理进本地库。

学校或机构订阅的文献，可以先在浏览器登录并下载，再通过“关联已下载 PDF”接到已有条目，或直接导入。软件目前不会监控浏览器下载目录，手动下载完成后需要做一次关联。

03｜按课题整理，也能一口气统一文件名

文献库支持课题分类、搜索、批量导入 PDF / 文件夹、补充元数据和阅读状态。文件命名可设置成 {年份}_{第一作者}_{标题}，也可以加入 DOI 或课题名称。

旧文件也能一起规范：右键文献选择 “按规则重新命名”，或点 “选择所有文献 / 选择所有已下载文献” 再批量处理。全库选择会清除当前筛选，执行前会显示改名预览；没有附件的条目跳过，同名自动加后缀，原始导入文件保持原样。

04｜打开 PDF 就能读，读到哪里记到哪里

从分类、图谱等软件内部入口打开 PDF，会进入统一的文献阅读区。翻页、跳页、缩放、适合宽度、书签都在手边，右侧笔记编辑后自动保存。

  • 阅读区右键记笔记：插入当前页记录；有当前页最近框选文字时一并带入。
  • 框选高亮和批注：拖出选区，标记重点、写下理解，之后从批注列表定位、编辑或删除。
  • 笔记编辑：支持加粗、斜体、撤销 / 重做、插入页码、研究笔记模板和导出。
  • 右键快速操作：还可以在点击位置添加批注，或给当前页加书签。

笔记和批注保存在本地文献库，不改写 PDF 原文件。因此换到其他阅读器时，不会自动出现这些批注；需要分享文字时可以导出笔记。

05｜参考文献不是终点，是继续探索的入口

阅读时可以单独唤出 参考文献侧栏。提取到的条目优先保留原文编号，方便和正文引用对应；标为“1*”等星号时表示只识别了提取顺序，需要回原文核对。

选中一条参考文献，直接查询原文、下载归档，或者先收藏到当前课题。读一篇论文时顺手收集下一篇，把阅读线索接起来。扫描版和复杂排版可能漏提取，当前不包含 OCR，未识别的条目仍可复制标题或 DOI 查询。

06｜把文件列表展开成可探索的关系图谱

“收藏概览”展示课题分布，“文献关系”展示本地文献之间的文本相似关系和 DOI 引用证据。通过标题、摘要、关键词以及提取到的参考文献，在本机完成计算。

  • 拖动文献数滑条控制显示数量，避免一开始就被密集节点淹没。
  • 滚轮缩放、拖动平移、Shift 框选区域放大，双击节点聚焦邻居。
  • 点击概览里的课题区域，继续查看该课题；选中节点后可读 PDF、找原文或收藏候选。
  • 按阅读次数、本地引用次数、是否下载调整高亮，也可自定义颜色和权重。

虚线候选来自本地提取的参考文献，提示“这篇可能值得继续收集”。它不是在线穷尽所有相关研究；本地引用数也不是全球被引数，文本相似不等于已验证的引用关系。

07｜昨天读了什么？点一下，弹出阅读回顾

标题栏 “阅读总结” 会弹出独立窗口，不占用一个主页面。默认回顾昨天，也可看今日或指定日期：读了几篇、每篇多久、总共多久，以及本地摘要、笔记和摘录，可以复制或导出。关闭弹窗，继续原来的阅读。

时间按你要求的口径统计：只有加载了 PDF 的阅读页处于前台主窗口才累计。切到别的页面、其他软件、最小化、托盘或休眠间隔都会暂停；约 1 秒采样，统计的是前台停留，不推断专注度。时长从新版开始记录，过去未记录的时间不会编出来。

回顾内容直接整理当前本地摘要、笔记和摘录，不调用外部 AI。它让你快速回到昨天的研究线索，而不是替你生成可能失真的结论。后台登录启动时保持安静，需要时再点开总结。

08｜设置集中在右上角，后台运行也更顺手

独立设置页提供 深空蓝、极光紫、石墨灰、极简浅色 四套皮肤，切换立即预览，保存后记住选择。快捷键可以自己改，冲突时会提示；也可选填 Unpaywall 联系邮箱补充开放版本来源。

关闭窗口收起到托盘，双击恢复；重复启动会唤起同一个实例。按需开启 “登录 Windows 后后台启动”，开机登录后驻留待用。真正退出请用托盘菜单。没有鼠标跟随浮窗，不需要注册本地账号。

09｜已有 EndNote 文献，可以接进来

目前针对 EndNote 22.3 提供只读导入、PDF 附件归档、字段差异和冲突预览，以及 XML 交换包。建议先用备份库测试，并同时保留 .enl 和对应 .Data 文件夹。

这里把范围说清楚：已有 EndNote 记录的全自动双向写回尚未实现。当前可导入到本地，再通过 XML 交换与清单核对完成回流；已有记录需人工检查，直接导入完整库可能重复。本软件的批注、图谱和阅读计时不会自动变成 EndNote 内部数据。

10｜第一次使用，照着这几步就够了

  1. 打开下面的 GitHub Release，下载 Windows 包，解压完整目录。
  2. 双击“文献直达.exe”，复制一个英文标题或 DOI，点击“粘贴并查找”。
  3. 核对结果，点击“收藏 / 下载归档”，创建你的第一个课题。
  4. 打开 PDF 阅读，右键记一条笔记；在分类列表设置命名规则。
  5. 需要浏览器右键时，在 edge://extensions 或 chrome://extensions 开启开发者模式并加载 browser-extension。
  6. 右上角设置快捷键与皮肤；之后用“阅读总结”弹窗回看阅读情况。

使用边界，也提前告诉你

  • 原文查询、网页访问与下载需要联网；标题 / DOI 会发送给文献检索服务。整理、阅读、图谱、总结在本机运行。
  • 开放入口不保证免费全文。付费文献可能需要机构订阅，预印本与正式版也可能不同，请核对。
  • 遇到公众号验证：在浏览器完成验证后，选中正文里的英文标题 / DOI 查询。
  • 全局选词需要可复制文字，扫描 PDF、禁复制或权限隔离的窗口可能无法读取；触发时会复制本次选词，更新剪贴板。
  • 请定期退出软件后备份整个“本地文献库”。升级时保留文献库与配置，只更新程序。
