论文、附件、笔记和引用，终于可以放在一起了

导师发来一个标题，合作者转来一篇推送。为了读到这篇论文，你复制、检索、找全文、下载、改名、分文件夹。开始阅读以后，补充材料在另一个窗口，想法记在另一处；到了写作，又要重新整理引用格式。

这些重复的小动作，是我做 文献直达 · PaperQuick 的起点。这次更新到 3.2，它把文献信息接到后面的整理、阅读、追踪和写作：查询原文 → 下载归档 → 课题分类 → 正文与附件比对 → 阅读笔记 → 文献发现 → Word 引用。

这是一个 Windows 本地软件，解压即可使用，不用安装 Python，不用注册账号。分类、阅读、图谱、回顾和引用排版不调用外部 AI，不需要 AI API Key。 检索和下载按需联网；Word 预览、Word 转 PDF 和插入引文需要电脑安装桌面版 Microsoft Word；PDF 转 Word 不需要。

01｜收到标题，顺手找到原文入口

支持英文论文标题、DOI、arXiv 编号或链接，以及能够读取正文的推送链接。结果会逐步显示标题、作者、年份、DOI 和开放全文、PDF 或出版社入口，方便先核对，再打开。

• 直接粘贴：点击“粘贴并查找”，或粘贴后按 Ctrl + Enter。
• 桌面选词：在 Word、PDF、微信电脑版等能复制文字的位置，选中标题或 DOI，按自定义快捷键查询；快捷键可以在右上角设置中修改。
• 浏览器右键：加载随包提供的 Edge / Chrome 扩展，选中文字，右键“查找文献并打开原文”；也可以查询当前推送页面。

有明确 DOI、arXiv 入口时优先打开。服务较慢时，“直接学术搜索”把当前内容带到搜索网站。遇到公众号验证，需要先在浏览器完成验证，或选中正文中的英文标题再查。

02｜找到原文，顺便自动归档

点击 “收藏 / 下载归档”，选择课题，没有就新建。可直接下载的开放 PDF 会自动保存、命名并归档；需要网页操作时，打开对应全文或出版社页面。分类列表右键也提供“打开下载页面”和“下载并自动归档”。

机构订阅文献可以先在浏览器登录、下载，再关联到对应条目。原文是否免费取决于开放情况和访问权限，软件不会绕过订阅。浏览器下载目录目前不会被自动监控，手动下载后需要关联一次。

03｜PDF 和 Word，放进同一个文献库

点击 “导入 PDF / Word”，导入 PDF、DOCX 或 DOC，也可以导入一个文件夹。软件收纳文件副本，保留原件；能提取的信息先自动填入，标题、作者、年份等仍可核对修改。Word 文件的导入不要求安装 Word，分页预览则需要本机桌面版 Word。

按课题分类、搜索、标记阅读状态；命名规则可设为 {年份}_{第一作者}_{标题}，也能加入 DOI 或课题名称。多选或一键选择所有文献、所有已下载文献，先看预览，再批量按规则改名。Word 保留实际扩展名，补充材料有自己的名称，网址不会被当作文件改名。

04｜正文、补充材料和附件链接，关联在一起

一篇论文可以关联多份材料：正文 PDF、Word 原稿、补充表格、研究方案、相关数据文件，以及补充材料网页。打开 “附件 / 比对” 或阅读页的 “正文与附件”，可以添加文件、添加网址、修改名称，或把一份 PDF / Word 设为正文。

正文和补充材料分别标记，只添加补充 PDF 不会被误认为已经下载全文。更换正文后，原正文的批注仍保留，切回原文件就能继续查看。网址保留为链接，其他类型附件可交给本机相应软件打开。

05｜正文在左，附件在右，独立翻页比对

读到 Supplementary Table 时，直接展开 “附件比对”。PDF 和 Word 附件都能分页阅读，两边独立翻页、跳页和缩放。左边停留在正文结果，右边查看具体数据；也可以对照正式发表版和原稿。需要记录想法时，再展开笔记。

附件比对区用于查看，不会把附件页码替换成正文页码。文献笔记保留在同一条目下，正文批注跟随对应文件保存。

06｜Word 与 PDF 互转，在页面里完成

点击 “Word / PDF 转换”，选择文件，用新名称另存。Word 转 PDF 用于阅读和分享。PDF 转 Word 提供两种方式：提取可编辑文字，保留正文和分页，方便继续整理；保留页面外观，每页转为图片，方便保留版面、在页面旁继续记录。勾选“转换后，将新文件作为附件收纳到当前文献”，结果就会留在这篇论文旁边，方便接着比对。分类列表右键也能进入转换。

两种 PDF 转 Word 方式都在本机完成，无需安装 Word。“可编辑文字”不还原图表、公式和复杂排版；扫描页保留为图片。“保留页面外观”的页内文字不能直接编辑。本版不提供 OCR，请按用途选择并核对结果。Word 转 PDF 使用本机桌面版 Word；两种方向都保留原件，不直接覆盖已有同名文件。

07｜读到哪里，笔记就记到哪里

阅读区支持翻页、跳页、适合宽度、缩放和书签。笔记可以直接编辑，自动保存在本地，也支持手动保存与导出。

• 阅读区右键添加笔记：带上当前页码，最近框选的文字也可一起记下。
• 框选高亮与批注：标记重点、写下理解，再从列表定位、修改、删除或换颜色。
• 笔记编辑：支持加粗、斜体、撤销、重做、插入页码和研究笔记模板。

笔记和批注存在本地文献库，不改写原 PDF；用其他阅读器打开原件时，不会自动出现这些批注。需要分享文字时可以导出笔记。

08｜顺着参考文献，继续发现下一篇

阅读时单独唤出 参考文献侧栏。识别到原编号时保留编号，方便对照正文；“1*”这样的星号表示只识别了提取顺序，需要回原文核对。选中条目后，可以查询原文、下载归档，或先收藏到课题。

阅读总结里的 “引用与被引” 还可以联网寻找：它引用了哪些论文，又有哪些论文引用了它。已经入库的条目会略过，新发现可继续查原文、收藏，并保留与起点文献的关系。当前使用 Europe PMC 公开数据，主要面向生命科学和医学，覆盖并非所有领域和数据库。

09｜把文件列表展开成文献关系图谱

收藏概览 展示课题分布，文献关系 展示本地文本相似关系和参考文献 DOI 引用证据。拖动文献数量滑条控制密度，滚轮缩放、拖动平移，Shift 框选区域放大，双击节点聚焦邻居。计算在本机完成。

可按阅读次数、本地被引次数、是否归档正文高亮，也能自定义颜色和权重。虚线候选提示尚未入库、值得继续查看的本地参考文献。本地引用数不是全球被引次数，文本相似也不等于已经验证的引用关系。

10｜打开回顾，接着昨天的思路往下读

右上角 “阅读总结” 打开独立弹窗。查看昨天、今天、近七天或指定日期，也能按课题筛选：读过哪些论文、每篇停留多久、摘要是什么、记下了什么问题，都可以一起回看、复制和导出。

时长只统计文献已打开、阅读页处于前台时的停留。切到其他软件、其他页面、总结窗口或收起到托盘就暂停。它记录页面停留，不判断是否读完或理解；升级前未记录的时间不会补算。回顾整理当前摘要、笔记和摘录，不调用 AI 生成研究结论。

11｜整理主题关键词，持续关注新文献

在 “主题与检索” 中，从课题收藏或最近读过的文献整理关键词。选择关注的词、手动补充，生成 PubMed、Web of Science、Google Scholar、Europe PMC 检索式，再编辑、复制或打开对应网站。Web of Science 会先复制检索式，再打开高级检索页面供粘贴。

把 Europe PMC 检索式保存到 “主题追踪”，可手动查找，或开启“每天检查一次（软件运行时）”。每次发现都有记录；撤回一批发现后可以恢复，已经收藏的论文、PDF 和笔记不会被删除。关闭软件后不会检查，也不会为此唤醒电脑。

12｜开始写作，把收藏直接插入 Word

在 Word 放好光标，从 文献分类 → Word 引用 连接文档，选择一篇或多篇文献，即可插入正文引文。到文末生成参考文献表。调整引用顺序、修改信息或更换格式以后，点击 “更新全部引用 / 切换格式”，正文和列表一起整理。每次更新可用 Word 撤销，文档仍需自行保存。

内置 31 套常用 CSL 格式：国标 GB/T 7714、APA、Vancouver、IEEE、MLA、Harvard、Chicago 作者年份，以及 Nature、Science、Cell、The Lancet、NEJM、AMA、ACS 等。还能导入更多期刊样式。引用信息可手工核对，也可按 DOI 从 Crossref 补全。

排版离线完成，无需 Word 宏。本版支持 Windows 桌面 Word 正文中的编号与作者年份引用，暂不支持脚注、尾注、Word 网页版和 WPS。软件只更新自己插入的引文，不会接管 EndNote、Zotero 或 Word 原生引用。

13｜已有 EndNote 文献，可以继续利用

针对 EndNote 22.3，提供只读导入、PDF 附件归档、字段差异和冲突预览，以及 XML 交换包。请先用备份库核对，保留 .enl 和对应 .Data 文件夹。

现阶段尚未实现已有 EndNote 记录的全自动双向写回。 本地修改可导出 XML 与交换清单，再在 EndNote 中导入或人工核对；完整库直接导入可能重复。本软件的批注、图谱和阅读计时不会自动成为 EndNote 内部数据。

14｜按自己的习惯设置，随时待用

右上角设置页提供 深空蓝、极光紫、石墨灰、极简浅色 四套主题，并支持自定义全局选词快捷键。关闭窗口收起到托盘，双击恢复；重复启动会唤起同一个窗口。可选开启 “登录 Windows 后后台启动”，真正退出使用托盘菜单。没有鼠标跟随浮窗。

第一次使用，先走完这几步

1. 下载 PaperQuick-v3.2-Windows.zip，解压到可写文件夹，运行“文献直达.exe”。
2. 粘贴标题或 DOI 查原文并收藏到课题，或导入已有 PDF / Word。
3. 进入“附件 / 比对”，添加补充材料或网址，确认正文文件。
4. 打开正文，展开附件比对，记一条笔记；需要时在阅读页转换文档。
5. 点开阅读总结整理后续线索，写作时用“Word 引用”插入文献。

检索、引用探索、主题追踪和下载需要联网，相关标题、DOI 或检索式会发送给文献服务。文档转换、正文、笔记和附件文件在本机处理。请定期退出软件后备份整个“本地文献库”；升级保留文献库和配置，只更新程序。
